## 🌟 La Experiencia
**Alumbrar** no es solo una aplicación; es un compañero en tu viaje hacia la paz interior. Diseñada para integrarse en tu vida cotidiana, te ofrece las herramientas necesarias para transformar tu percepción y recordar la Verdad que habita en ti.

## 🌈 El Camino Diario
- **Gemas de Luz**: Inspiración instantánea para cada momento del día, con ideas guía y microacciones prácticas.
- **El Guía**: Un espacio de diálogo profundo para resolver dudas del ego y encontrar claridad en las enseñanzas del Curso.
- **Sabiduría de las Lecciones**: Acércate a las 365 lecciones con resúmenes claros y profundos que iluminan tu práctica diaria.
- **Tu Diario Digital**: Guarda tus gemas favoritas y accede a tus conversaciones pasadas para ver tu progreso en el camino.

## ✨ Tecnología al Servicio del Espíritu
Aprovechamos la tecnología más avanzada para crear un puente hacia lo eterno:
- **Interfaz de Paz**: Diseño minimalista y sereno que invita al silencio.
- **Conexión Consciente**: Inteligencia entrenada para reflejar fielmente la filosofía de UCDM.
- **Privacidad y Calma**: Tu progreso está protegido y siempre a tu disposición.

## 🛠️ Para Desarrolladores (Setup)

### 1. Requisitos
- Node.js (Vite + React)
- Cuenta en Supabase para persistencia.

### 2. Instalación
```bash
npm install
```

### 3. Configuración (`.env.local`)
```env
VITE_GEMINI_API_KEY=tu_api_key_aqui
VITE_SUPABASE_URL=tu_url_aqui
VITE_SUPABASE_ANON_KEY=tu_anon_key_aqui
```

### 4. Lanzamiento
```bash
npm run dev
```
